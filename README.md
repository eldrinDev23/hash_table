# Hash Table in C

## Description
This project implements a **Hash Table** using the C programming language. It stores and manages data using a hash function to calculate the index for each element.

## Features
- Insert elements into the hash table.
- Search for elements.
- Delete elements.
- Display the hash table.
- Handle collisions (if implemented).

## Technologies Used
- C Programming
- GCC Compiler

## How to Run

**1. Clone the repository**
```bash
git clone https://github.com/eldrinDev23/hash_table.git
```

**2. Open the project folder**
```bash
cd hash_table
```

**3. Compile the program**
```bash
gcc hash_table.c -o hash_table.exe
```

**4. Run the program**
```bash
./hash_table.exe
```
